> CLASS DOSSIER // FARRAGUT

BATTLESHIP // TECH BASE: STAR LEAGUE
[ CLASS SUMMARY // FARRAGUT ]

First commissioned by the Terran Hegemony in 2472, the 1,680,000-ton Farragut-class battleship was the mightiest dreadnought of the 25th century prior to the introduction of the McKenna-class. Built around an immense 120-point structural frame and 1,480 tons of Lamellor Ferro-Carbide armor, it mounted fifty-four heavy naval autocannons and eight Heavy Naval PPCs.
