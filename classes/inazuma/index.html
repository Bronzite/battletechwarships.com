> CLASS DOSSIER // INAZUMA

CORVETTE // TECH BASE: INNER SPHERE
[ CLASS SUMMARY // INAZUMA ]

A 200,000-ton Draconis Combine Admiralty corvette constructed at the expanded orbital facilities of Midway Shipyards above Midway. Forming the Combine Navy's fast escort contingent—with hulls Night of Agony, Winds of Heaven, Amber Lotus, and Swiping Claw active prior to the Jihad and Winds of Heaven remaining active into 3145—the class carried a high procurement cost of 11.67 billion C-bills.
