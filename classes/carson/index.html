> CLASS DOSSIER // CARSON

DESTROYER // TECH BASE: STAR LEAGUE
[ CLASS SUMMARY // CARSON ]

Built by Thompson's Shipyards at Keid from 2632 as a long-endurance patrol destroyer for expanding Star League frontiers, the 510,000-ton Carson-class carried an 80-meter grav deck and 8,000-ton fuel bunkers. Severe Regulis-XII drive wear forced production to halt early and confined surviving hulls to settled space until replaced by the Essex-class in 2722.
