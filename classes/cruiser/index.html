> CLASS DOSSIER // CRUISER

CRUISER // TECH BASE: INNER SPHERE
[ CLASS SUMMARY // CRUISER ]

First introduced in 2325, the literal Cruisers-class vessel was an early Terran Hegemony-era 500,000-ton WarShip armed uniformly with six-gun NAC/10 bays and capital missile batteries in every arc plus a 10,000-ton DropShuttle bay. Older surplus Cruisers remained in Draconis Combine Admiralty reserve service as late as 2765.
