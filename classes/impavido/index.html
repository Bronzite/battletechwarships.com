> CLASS DOSSIER // IMPAVIDO

DESTROYER // TECH BASE: INNER SPHERE (FREE WORLDS LEAGUE)
[ CLASS SUMMARY // IMPAVIDO ]

Constructed at the progressions of the Atreus Shipyards by the Free Worlds League in 3058, the 490,000-ton Impavido-class destroyer is a high-speed 4.0G fleet escort. Armed with eight NAC/20s, eight Naval Laser 35s, and eight Barracuda missile tubes while carrying 18 aerospace fighters and two DropShips, it formed the rapid-response core of the Free Worlds League Navy.
