> CLASS DOSSIER // DART

LIGHT CRUISER // TECH BASE: STAR LEAGUE
[ CLASS SUMMARY // DART ]

Built by DiTron Heavy Industries from 2305 during the Terran Alliance era as a rugged, six-collar independent explorer and convoy warship, the 680,000-ton Dart-class light cruiser mounted reliable Century 4000 drives and 1,194 tons of standard armor. Disarmed hulls sold to Periphery realms fought into the Reunification War, with the last known Dart destroyed by SLS Gettysburg during the 2722 New Vandenberg revolt.
