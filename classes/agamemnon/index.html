> CLASS DOSSIER // AGAMEMNON

HEAVY CRUISER // TECH BASE: INNER SPHERE
[ CLASS SUMMARY // AGAMEMNON ]

An 815,000-ton Free Worlds League Navy heavy cruiser produced by Imstar Aerospace using zero-gravity refining facilities above Atreus. Equipped with onboard hyperpulse generators operated by Word of Blake communications specialists, four Agamemnon-class cruisers—Menelaus, Aeneas, Hippolyta, and Troy—entered FWLN service prior to the Jihad.
