BATTLESHIP // TECH BASE: CLAN
[ CLASS SUMMARY // NIGHTLORD ]

Built around existing Monsoon-class battleship spaceframes beginning in 2932, the 1,200,000-ton Nightlord-class battleship is a Clan fleet command and planetary invasion vessel. Able to carry 100 OmniMechs and 100 Points of Elementals directly inside its internal bays alongside four docked DropShips, it mounts Medium Naval Gauss Rifles, Heavy Naval PPCs, and NAC/30 and NAC/35 broadsides.
