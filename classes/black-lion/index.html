> CLASS DOSSIER // BLACK LION

BATTLECRUISER // TECH BASE: STAR LEAGUE / CLAN
[ CLASS SUMMARY // BLACK LION ]

First deployed in 2691, the 810,000-ton Black Lion-class battlecruiser was considered one of the finest close-range brawlers in the Star League Defense Force Navy. Combining 2.5G flank thrust, thick Lamellor Ferro-Carbide armor, four DropShip collars, and massive NAC/25, NAC/30, NAC/35, and NAC/40 naval autocannon batteries, it served as the flagship class for Clan Nova Cat, ComStar's Second Fleet, and Clan Smoke Jaguar.
