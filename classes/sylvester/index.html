TRANSPORT // TECH BASE: STAR LEAGUE
[ CLASS SUMMARY // SYLVESTER ]

Conceived by Lyran merchant-noble Graf Hans Sylvester and built by Ioto Galactic Enterprises on Alarion in 2499, the 280,000-ton Sylvester-class merchant ship was the most heavily armed civilian capital freighter ever launched. Prohibitively expensive at only four hulls built before cancellation, its blueprint directly inspired the Terran Hegemony's military Carrack transport.
