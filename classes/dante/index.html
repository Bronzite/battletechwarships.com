> CLASS DOSSIER // DANTE

FRIGATE // TECH BASE: STAR LEAGUE / INNER SPHERE (COMSTAR)
[ CLASS SUMMARY // DANTE ]

Built secretly at ComStar's renovated Titan shipyards between 2935 and 2949 to field heavily automated frigates requiring minimal crews, three 610,000-ton Dante-class hulls—Narbonne (2941), Bordeaux (2944), and Montpellier (2948)—delivered 4.0G peak acceleration and heavy Naval Autocannon firepower to anchor early Com Guard flotillas.
