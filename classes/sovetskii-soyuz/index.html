> CLASS DOSSIER // SOVETSKII SOYUZ

HEAVY CRUISER // TECH BASE: STAR LEAGUE / CLAN
[ CLASS SUMMARY // SOVETSKII SOYUZ ]

Introduced in 2742 by Titan Yards to gradually replace the aging Aegis-class, the 830,000-ton Sovetskii Soyuz-class heavy cruiser features five DropShip docking collars, automated fire-control systems that reduce gunner crew requirements by more than half, twin nose Heavy Naval PPCs, and four AR10 capital missile launchers.
