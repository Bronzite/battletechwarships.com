> CLASS DOSSIER // MAKO

CORVETTE // TECH BASE: STAR LEAGUE
[ CLASS SUMMARY // MAKO ]

Built by Bolson Shipyards of New Kyoto from 2692 to give the Lyran Commonwealth Navy a high-speed 4.5G border interceptor, over one hundred 200,000-ton Mako-class corvettes saw service with the LCAF, SLDF, and Rim Worlds Republic. Armed with NAC/25 broadsides, Light and Medium NPPCs, and Improved Ferro-Aluminum armor, the final Mako fell defending Caledonia in 2841.
