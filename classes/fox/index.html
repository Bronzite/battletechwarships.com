> CLASS DOSSIER // FOX

CORVETTE // TECH BASE: INNER SPHERE (FEDERATED COMMONWEALTH)
[ CLASS SUMMARY // FOX ]

Named in honor of First Prince Hanse Davion ('The Fox') and built at the Port Simon Naval Yard on Galax by Federated-Boeing and Universal Air, the 240,000-ton Fox-class corvette was the first modern WarShip class constructed by the Federated Commonwealth. Based on Star League Bonaventure-class plans, it features five DropShip collars, an extraordinarily tough 100-point structural frame, eight Barracuda missile tubes across all arcs, and NAC/10 and Naval Laser batteries.
