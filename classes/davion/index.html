[ CLASS SUMMARY // DAVION ]

First commissioned by the Federated Suns in 2510 before First Prince Alexander Davion overhauled the program with the 580,000-ton Block II in 2552, surviving Block I Davion-class destroyers were leased to the SLDF ahead of the Reunification War and later rebuilt as Whirlwind-class destroyers that accompanied the Exodus and entered Clan fleets.
