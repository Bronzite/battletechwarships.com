CARRIER // TECH BASE: INNER SPHERE
[ CLASS SUMMARY // THERA ]

Built by Illium Naval Engineering at Ionus with assistance from the Word of Blake, the 960,000-ton Thera-class carrier formed the command core of Free Worlds League Navy battle groups. Six hulls—FWLS Santorini, Sardis, Corinth, Delphi, Delos (3068), and Thessaly (3070)—were built, each carrying an onboard HPG suite and anchoring Eagle-class escort pairs.
