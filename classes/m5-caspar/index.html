> CLASS DOSSIER // M-5 CASPAR

DESTROYER // TECH BASE: INNER SPHERE
[ CLASS SUMMARY // M-5 CASPAR ]

Built upon heavily modified unequipped Lola Block II hulls starting in 2710, the 680,000-ton M-5 Caspar automated Space Defense System (SDS) capital drone surrendered crew and cargo space for ASRCS AI control suites (Gunnery 3, Piloting 4), automated anti-boarding defenses (110 Marine Points), a self-destruct mechanism in the engine compartment, and capital weaponry rivaling a battleship. Over 250 M-5s defended Terra alongside Hegemony worlds before SLDF ECM countermeasures and Kerensky's post-war purge eliminated the network.
