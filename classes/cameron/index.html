> CLASS DOSSIER // CAMERON

BATTLECRUISER // TECH BASE: STAR LEAGUE / CLAN
[ CLASS SUMMARY // CAMERON ]

First laid down in 2672 and reaching full fleet production for the SLDF Navy in 2688, the 860,000-ton Cameron-class battlecruiser was built as a command ship and heavy capital combatant. Characterized by boxy flanks, massive Cassion Vassers maneuvering drives, and a devastating mix of Naval Autocannon/30s, NAC/35s, Heavy Naval PPCs, and AR10 capital missile launchers, it served both ComStar's First Fleet and the Clans.
