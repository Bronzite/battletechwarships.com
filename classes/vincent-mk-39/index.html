> CLASS DOSSIER // VINCENT MK. 39

CORVETTE // TECH BASE: INNER SPHERE
[ CLASS SUMMARY // VINCENT MK. 39 ]

Later Star League-era refinement of the Terran Hegemony's classic 25th-century Vincent-class patrol corvette, the 420,000-ton Mk. 39 mounted Barracuda launchers, NAC/10s, and Large Lasers. Widely operated by SLDF forces and Great House navies—and clandestinely restarted in Capellan Delhi WarShips yards after 2766—the Mk. 39 laid the groundwork for the later Clan-refitted Vincent Mk. 42.
