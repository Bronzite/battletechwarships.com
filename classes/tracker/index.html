> CLASS DOSSIER // TRACKER

SURVEILLANCE // TECH BASE: STAR LEAGUE
[ CLASS SUMMARY // TRACKER ]

Commissioned on the orders of Director-General Judith Cameron in 2407, the 120,000-ton Tracker-class surveillance ship used spoofable transponders and attachable hull silhouette panels to impersonate commercial JumpShips while gathering intelligence. Data collected by THS Marlow enabled the 2409 liberation of Terra Firma, and surviving Trackers served through the Reunification War as anti-pirate Q-Ships.
