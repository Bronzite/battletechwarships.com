> CLASS DOSSIER // CONQUEROR

BATTLECRUISER // TECH BASE: CLAN
[ CLASS SUMMARY // CONQUEROR ]

Converted by Clan Snow Raven from two Star League-era Kimagure-class pursuit cruisers taken on the Exodus, retaining the Kimagure's signature hatchetface prow while packing heavy naval autocannons, naval lasers, capital missiles, 100 aerospace fighters across eight bay doors, two DropShip collars, and an onboard HPG. First unit CSR Conqueror and sister CSR Ark Royal anchored Snow Raven naval stars from the Jihad through 3151.
