> CLASS DOSSIER // TATSUMAKI

DESTROYER // TECH BASE: INNER SPHERE
[ CLASS SUMMARY // TATSUMAKI ]

A 520,000-ton Draconis Combine destroyer built by Stellar Trek Enterprises at dedicated WarShip yards above Dieron. Program delays and logistical strain plagued construction, leaving only DCS Lair of Mighty Wyrms active in the pre-Jihad fleet, where it went on to serve in Operation SCOUR over Terra.
