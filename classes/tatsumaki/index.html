DESTROYER // TECH BASE: INNER SPHERE
[ CLASS SUMMARY // TATSUMAKI ]

A 520,000-ton Draconis Combine destroyer built by Stellar Trek Enterprises above Dieron to escort troop JumpShips and conduct close-range boarding assaults with a full battalion (108 troopers) of battle armor marines. Chronic technical bugs forced each ship to carry nearly double the standard engineering crew; DCS Dragon's Last Tear perished in the rogue 3062 attack on Alshain, leaving only DCS Lair of Mighty Wyrms active in 3067 through Operation SCOUR.
