> CLASS DOSSIER // DREADNOUGHT

BATTLESHIP // TECH BASE: STAR LEAGUE / TERRAN ALLIANCE
[ CLASS SUMMARY // DREADNOUGHT ]

Launched in 2300 with Admiral James McKenna's flagship TAS Dreadnought, this 960,000-ton seven-ship class was humanity's first true capital combat WarShip. Armed exclusively with heavy Naval Autocannons and retrofitted standard AC/2 and AC/5 point-defense batteries, the surviving Dreadnoughts were pressed into service for the Reunification War before formal retirement in 2602; the final active hull, SLS Dreadnought, fell escorting refugees during the Amaris Coup.
