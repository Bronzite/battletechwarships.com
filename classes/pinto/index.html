> CLASS DOSSIER // PINTO

CORVETTE // TECH BASE: STAR LEAGUE
[ CLASS SUMMARY // PINTO ]

Constructed by the Rim Worlds Republic from 2502 and restarted during Tedeo Amaris' 2650 naval buildup, the 160,000-ton Pinto-class corvette outpaced, outgunned, and out-armored the Star League's Vincent corvettes. Carrying twelve fighters and a DropShip docking collar, Pintos spearheaded Stefan Amaris' coup before being hunted to extinction during Kerensky's liberation campaigns.
