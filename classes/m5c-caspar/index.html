> CLASS DOSSIER // M-5C CASPAR (ATAC COMMAND CAPITAL DRONE)

DESTROYER // TECH BASE: INNER SPHERE
[ CLASS SUMMARY // M-5C CASPAR (ATAC COMMAND CAPITAL DRONE) ]

Command variant of the M-5 Caspar automated WarShip drone mounting the Autonomous Tactical Analysis Computer (ATAC), enabling each M-5C to coordinate tactical simulations across up to fifty linked SDS drones. While accommodating the ATAC array downgraded its local drone computer (Gunnery 4, Piloting 5), the M-5C relied on networked targeting and doubled its nose Heavy NPPC battery to four guns (1,260 nose heat; BV 100,128).
