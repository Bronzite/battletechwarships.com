> CLASS DOSSIER // LOLA II

DESTROYER // TECH BASE: STAR LEAGUE
[ CLASS SUMMARY // LOLA II ]

Built by Blue Nose Clipperships under Boeing Interstellar license from 2622, the 680,000-ton Lola II replaced some autocannon mounts and conventional lasers with Barracuda missile tubes. Critical fuel-system defects prompted the SLDF to order all hulls decommissioned and scrapped in 2660, though at least four resurfaced in Taurian rebel hands during the Second Periphery Uprising.
