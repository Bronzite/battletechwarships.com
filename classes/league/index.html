> CLASS DOSSIER // LEAGUE

DESTROYER // TECH BASE: INNER SPHERE
[ CLASS SUMMARY // LEAGUE ]

Assembled at the specially built SelaSys yards on Loyalty from components across the Free Worlds League starting in 2368, the rugged 550,000-ton League-class destroyer anchored FWLN fleets as an anti-piracy patroller and Atreus escort—its last active Block I, FWLS Palatine, falling to a McKenna battleship during a raid into Capellan space before a 2768 Gauss-armed Block II revival.
