> ENGAGEMENT LOG // OPERATION LIBERATION: TERRAN SYSTEM JUMP & TASK FORCE LEONIDAS

DATE: 2777-01-23 // SYSTEM: TERRA
[ ACTION LOG // OPERATION LIBERATION: TERRAN SYSTEM JUMP & TASK FORCE LEONIDAS ]

As 932 SLDF WarShips and JumpShips entered the Terran system on 23 January 2777 (suffering a catastrophic jump interpenetration between SLS Richardson and SLS Mississippi Queen), Task Force Leonidas spearheaded by Stefan Amaris-class battleship SLS Chieftain fought a 42-hour sacrifice battle against Terra's Reagan Defense Network while cis-lunar screens lost SLS Van Gogh.
